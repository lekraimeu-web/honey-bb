PUT YOUR PHOTOS IN THIS FOLDER
==============================

Any .jpg, .jpeg, .png or .webp file you drop here appears automatically
in the 3D Polaroid gallery. Nothing else to edit.

Naming
------
Photos are shown in alphabetical order, so name them with numbers:

  01.jpg
  02.jpg
  03.jpg
  ...

Captions (optional)
-------------------
Open  src/content/photos.js  and write a caption for each file name.

Tips
----
- 4 to 12 photos works best.
- Keep each file under ~1 MB for fast loading (a phone photo resized to
  1600px on its longest side is perfect).
- iPhone .HEIC files do NOT work in browsers: export them as .jpg first.
- Portrait, landscape and square photos are all fine; the Polaroid frame
  adapts to each photo so nothing gets stretched.
