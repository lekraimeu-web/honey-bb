MUSIC AND SOUNDS
================

music.mp3   (optional)  The soundtrack. Put here an instrumental you are
                        allowed to use (for example a licensed instrumental
                        of "Margaret" by Lana Del Rey feat. Bleachers, or any
                        royalty-free piano piece). It starts when she presses
                        "Yes, of course" and loops softly. If this file is
                        missing, the site falls back to its own built-in
                        generative ambient music, so nothing breaks.

meow.mp3    (optional)  A soft kitten meow. If missing, the site uses a small
                        synthesized meow instead.

Formats: .mp3 works everywhere. Keep music.mp3 under ~8 MB.
No copyrighted audio is included in this project.
